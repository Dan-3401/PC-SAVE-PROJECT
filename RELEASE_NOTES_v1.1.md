# PC SAVE PROJECT v1.1

This release adds complete in-game localization for **Chinese, Japanese, and English**.

## Highlights

- Added full Japanese and English translations for all 536 dialogue blocks.
- Added localized character names and Ren'Py system/menu text.
- Added an in-game language selector.
- Languages can be changed from the title screen or during gameplay through **Settings → Language**.
- Existing save, rollback, and menu behavior is preserved.

## Download

- `PCSAVEPROJACKT-1.1-pc-multilingual.zip` for Windows and Linux.
- The macOS v1.0 build remains available from the previous release.

## Language Switching

Open **设置 / 設定 / Settings**, then select:

- 中文
- 日本語
- English
