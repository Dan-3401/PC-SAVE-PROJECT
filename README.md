## What Is This?

**PC SAVE PROJECT**，中文可意译为 **PC 拯救计划**，是一款使用 Ren'Py 制作的 GALGAME。

标题里的 **SAVE** 同时指向“拯救”和“存档”：在游戏里，真正拯救 PC 的办法，正是依靠你的 save。

Version 1.1 adds complete Chinese, Japanese, and English localization. You can switch languages from **Settings → Language** on either the title screen or the in-game menu.

This repository is the public release hub: downloads, checksums, release notes, and the project intro page live here.

## Notes

Keep the extracted game folder together and run `PCSAVEPROJACKT.exe` on Windows or `PCSAVEPROJACKT.sh` on Linux. To change language, open **设置 / 設定 / Settings** and choose **中文 / 日本語 / English**.

The Japanese and English scripts in v1.1 are complete machine-translated drafts and may receive editorial improvements in later releases.

Current visual assets were generated with ChatGPT.
